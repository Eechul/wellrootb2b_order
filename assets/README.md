# assets — 앱에 쓰이는 그림

파일 이름을 **정확히** 아래와 같이 맞춰 이 폴더에 두면 자동으로 쓰입니다.
없어도 앱은 그림 없이 정상 동작합니다.

| 파일 | 쓰이는 곳 | 형식 | 규격 | 상태 |
|---|---|---|---|---|
| `app.ico` | exe 아이콘 **+** 창 제목 왼쪽 | ICO | 정사각형, 16~256px를 **한 파일에** | ✅ 있음 |
| `footer.png` | 실행 창 **맨 아래** | PNG | **가로 696px 고정**, 세로 40~80px | 없음 (선택) |

## app.ico — 이미 만들어져 있음

WellRoot 로고에서 **나무+화살표 심볼만** 잘라 만들었습니다.
**16·24·32·48·64·128·256px 7가지**를 한 파일에 담았고 배경은 투명입니다.

**로고 전체(글자 포함)를 쓰지 않은 이유:** 16px에서 "Well Root 웰루트 발주 도우미"는
읽을 수 없는 얼룩이 됩니다. 앱 아이콘은 로고 전체가 아니라 **심볼**을 쓰는 게 맞습니다.

### 로고가 바뀌면 다시 만들기

```powershell
# 새 로고를 assets\logo_source.png 로 저장한 뒤
python assets\make_icon.py
```

`Pillow`가 필요합니다(`pip install pillow`). 잘라낼 영역은 스크립트 안의 `SYMBOL_BOX`로 조정합니다.
실행하면 `icon_preview.png`가 같이 나오니 **작은 크기에서 어떻게 보이는지 꼭 확인**하세요
(밝은 배경·어두운 배경 둘 다 그려줍니다).

### 직접 만드실 경우

- **여러 크기를 하나의 .ico에** 담아야 합니다. 256px 한 장만 넣으면 작업표시줄·탐색기에서 뭉개집니다.
- 정사각형이어야 합니다. 가로로 긴 로고는 여백을 넣어 정사각형으로 만들어주세요.
- [icoconvert.com](https://icoconvert.com)에서 "Multi-size in one icon" 선택.

## footer.png (아직 없음, 선택)

- **가로 696px에 맞춰주세요.** 창 기본 너비 720px에서 좌우 여백을 뺀 크기입니다.
- **Tkinter는 그림 크기를 조절하지 못합니다.** 넣어주신 크기 그대로 그려지므로,
  더 크면 창이 밀리고 작으면 가운데에 작게 붙습니다.
- 세로는 40~80px 권장. 그보다 크면 로그 영역이 줄어듭니다.
- PNG만 됩니다(JPG·WEBP 안 됨). 투명 배경 지원.

## 넣은 뒤

```powershell
python app.py      # 빌드 없이 바로 확인
.\build.ps1        # exe에 동봉해서 빌드
```

`build.ps1`이 이 폴더를 통째로 exe에 넣고, `app.ico`를 exe 아이콘으로도 씁니다.
